# DamageLife Changelog

## 1.3.4.13 FIX 4 — масштабный фикс

> Исправляющая сборка стабильной ветки `1.3.4.13`. Номер версии не меняется.

### 🔧 Интерфейс и Layout
- Исправлен вертикальный перекос редактора выбранного контроля.
- Разнесены `Имя файла`, поле имени, строка `Файл: ...` и заголовок редактора фраз.
- Убрано наложение описаний и управляющих элементов.
- Шесть строк пользовательских фраз выровнены по единой вертикальной сетке.
- Кнопки проверки звука и файла больше не конфликтуют с соседними элементами.
- Исправлена вёрстка `Общие → Анонсы и эмоции`: описание, чекбоксы, ползунки и фразы размещены с нормальными отступами.

### 🎯 Контроль
- Входящий контроль: `Меня контролируют: ...`.
- Исходящий контроль получил отдельные фразы по типу способности.
- `Запрет чар`: `Запрещаю <цели> использовать магию: <заклинание>!`.
- Сбитие каста: `Я сбил <заклинание> с помощью <прерывания>!`.
- Старые шаблоны автоматически мигрируют на новые формулировки.
- Редактор разделяет направления контроля: **на мне / на врага**.

### 🔄 Peer-проверка версий
- `WHISPER` используется только для союзных игроков.
- Вражеские и неопределённые цели не получают личный запрос версии.
- Сохранена peer-проверка через addon-каналы в БГ, группе, рейде и гильдии.
- В открытом мире используются доступные player units: `target`, `mouseover`, `focus` и arena units.
- Старые версии DamageLife без peer-механизма просто не отвечают.
- Совпадение версий корректно отображается как результат проверки.

### 🪟 Target Window
- Уменьшена амплитуда анимации внимания.
- Пульсация и увеличение карточки стали мягче.
- Сохранены подсветка и текстовые боевые предупреждения.

### 🎙️ Озвучка
- `CRITICAL / BURST / EXECUTE / CONTROL` больше не зависят от старых хилловских переключателей.
- Единый режим `VOICE/GONG` сохранён.
- При невозможности воспроизвести голос используется резервный гонг.
- Встроенные мужские OGG: mono 44.1 kHz Vorbis.

### ⚔️ Анонсы и эмоции
- Старые Lifesaver-фразы спасения/исцеления автоматически заменяются на DPS-фразы.
- Базовые сообщения переведены на давление, бурст, пробитие защиты, прерывание, контроль, добивание и крит.
- Публичные эмоции больше не используют старую Lifesaver-механику спасения.

### Compatibility
- World of Warcraft 3.3.5a
- Interface `30300`
- TOC version: `1.3.4.13`
- Без BAT/EXE/PS1 и внешнего updater.

## 1.3.4.13 FIX 2

### Fixed
- Ручная peer-проверка версий теперь завершается через 2.5 секунды и показывает результат в чате.
- Совпадающая версия больше не выглядит как «ничего не произошло»: показываются ответы игроков и их версии.
- Таймер результата проверки вынесен в отдельный frame и не зависит от стартового login timer.
- Target Window получил усиленную визуальную систему внимания: крупная верхняя плашка, вспышка, пульсация и увеличение карточки.
- Для опасных целей отображаются заметные статусы `ОПАСНАЯ ЦЕЛЬ`, `ПРИОРИТЕТ • KILL` и `EXECUTE • УБИВАТЬ`.
- BG Timer усилен резервным определением активного БГ через `GetBattlefieldStatus()`.
- Исправлено скрытие anchor при создании активного таймера.
- Добавлены дополнительные локализованные названия карт для определения БГ.

### Compatibility
- WoW 3.3.5a
- Interface `30300`
- TOC version remains `1.3.4.13`

## 1.3.4.13 FIX — стабильная сборка

### Added
- Peer version check через `SendAddonMessage` / `CHAT_MSG_ADDON`.
- Автоматическая проверка в БГ, группе, рейде и гильдии.
- Проверка текущей цели и `mouseover` в открытом мире.
- Ручная кнопка **«Проверить игроков»** в `/dl → О проекте`.
- Чат-уведомление при обнаружении более новой версии.

### Fixed
- Исправлено направление вертикальных scrollbar в настройках.
- Добавлен видимый трек scrollbar и синхронизация с фактической прокруткой.
- Исправлена доступность заголовка окна при перемещении за пределы экрана.
- Перенесён выбор языка в «О проекте».
- Исправлен popup выбора шрифта.
- Исправлено позиционирование элементов прокручиваемых страниц.
- Исправлен текст режима перемещения плашки.
- Убран тестовый `/dlswitchtest` из стабильной сборки.

### Update Check Safety
- Нет BAT/EXE/PS1.
- Нет автоматической замены файлов.
- Нет постоянного polling.
- Запросы ограничены cooldown.
- Одинаковая новая версия не вызывает повторные уведомления.
