# DamageLife Changelog

## 1.3.4.13 FIX 2

### Fixed
- Ручная peer-проверка версий теперь завершается через 2.5 секунды и показывает результат в чате.
- Совпадающая версия больше не выглядит как «ничего не произошло»: показываются ответы игроков и их версии.
- Таймер результата проверки вынесен в отдельный frame и не зависит от стартового login timer.
- Target Window получил усиленную визуальную систему внимания: крупная верхняя плашка, вспышка, пульсация и увеличение карточки.
- Для опасных целей отображаются заметные статусы `ОПАСНАЯ ЦЕЛЬ`, `ПРИОРИТЕТ • KILL` и `EXECUTE • УБИВАТЬ`.
- BG Timer усилен резервным определением активного БГ через `GetBattlefieldStatus()`.
- Исправлено скрытие anchor при создании активного таймера.
- Добавлены дополнительные локализованные названия карт для определения БГ.

### Compatibility
- WoW 3.3.5a
- Interface `30300`
- TOC version remains `1.3.4.13`

## 1.3.4.13 FIX — стабильная сборка

### Added
- Peer version check через `SendAddonMessage` / `CHAT_MSG_ADDON`.
- Автоматическая проверка в БГ, группе, рейде и гильдии.
- Проверка текущей цели и `mouseover` в открытом мире.
- Ручная кнопка **«Проверить игроков»** в `/dl → О проекте`.
- Чат-уведомление при обнаружении более новой версии.

### Fixed
- Исправлено направление вертикальных scrollbar в настройках.
- Добавлен видимый трек scrollbar и синхронизация с фактической прокруткой.
- Исправлена доступность заголовка окна при перемещении за пределы экрана.
- Перенесён выбор языка в «О проекте».
- Исправлен popup выбора шрифта.
- Исправлено позиционирование элементов прокручиваемых страниц.
- Исправлен текст режима перемещения плашки.
- Убран тестовый `/dlswitchtest` из стабильной сборки.

### Update Check Safety
- Нет BAT/EXE/PS1.
- Нет автоматической замены файлов.
- Нет постоянного polling.
- Запросы ограничены cooldown.
- Одинаковая новая версия не вызывает повторные уведомления.
