# DamageLife — Updates

## 1.3.4.14

### Update Checker

- Переработана система проверки обновлений с приоритетом производительности.
- Убраны пользовательские BAT/PS1/EXE-компоненты.
- Нет постоянного polling.
- Нет `OnUpdate`-таймера для обновлений.
- Автоматическая проверка ограничена одним запросом в 24 часа.
- Проверка не выполняется во время боя или БГ/арены.
- Используется только асинхронный backend.
- Синхронные HTTP-библиотеки намеренно не используются, чтобы исключить блокировку UI.
- Состояние последней проверки хранится в SavedVariables.
- Автоматическая загрузка и замена файлов аддона отсутствуют.

### Производительность

Update Checker не участвует в боевом цикле DamageLife. При отсутствии host/relay backend после загрузки модуля не создаётся фоновой сетевой активности.

### Ограничение стандартного WoW 3.3.5a

Обычный addon Lua не получает произвольный HTTPS API. Поэтому настоящая интернет-проверка требует асинхронного backend, предоставленного инфраструктурой клиента/сервера. Без него DamageLife не создаёт ложных результатов.
