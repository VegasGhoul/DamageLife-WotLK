# DamageLife — Updates

## v1.3.4.13 FIX — стабильная сборка

### Проверка обновлений
- Добавлена peer-проверка версии DamageLife через addon-сообщения, по схеме, близкой к ElvUI.
- Проверка не зависит от HTTP/HTTPS и не требует BAT/EXE/PS1 или внешнего запуска.
- В БГ, группе и рейде версии сравниваются через общий addon-канал.
- В открытом мире автоматически используются гильдейский канал, текущая цель и игрок под мышью.
- Добавлена ручная кнопка **«Проверить игроков»** в `/dl → О проекте`.
- При обнаружении более новой версии выводится сообщение в чат с номером версии и указанием, что обновление доступно на GitHub.
- Добавлены cooldown для запросов и защита от повторного уведомления об одной и той же версии.
- Автоматической загрузки, распаковки или замены файлов аддона нет.

### Интерфейс и исправления
- Исправлено направление пользовательских полос прокрутки: верх страницы соответствует верхнему положению бегунка, низ — нижнему.
- Добавлен постоянный видимый трек прокрутки и корректный размер бегунка.
- Окно настроек увеличено до 880×570 и при этом оставлено более компактным по высоте.
- Окно можно частично вынести за экран, но заголовок всегда остаётся доступным для возврата.
- Выбор языка перенесён в раздел «О проекте».
- Исправлено отображение списка шрифтов: popup поднят над фоном настроек.
- Исправлено позиционирование элементов прокручиваемых страниц.
- Уточнён текст режима перемещения плашки.
- Сохранено отображение SWITCH-уведомления без автоматической смены цели.
- Тестовый `/dlswitchtest` удалён из стабильной сборки.

### Совместимость
- Interface: `30300` / WoW 3.3.5a.
- Версия TOC остаётся **1.3.4.13**; это FIX-сборка без изменения версии API.
