# DamageLife — Updates

## v1.3.4.13 FIX 4 — масштабный фикс

> **Стабильная ветка:** `1.3.4.13`  
> **Тип обновления:** исправления интерфейса, контроля, уведомлений и peer-проверки  
> **WoW:** 3.3.5a / Interface `30300`

FIX 4 — крупная исправляющая сборка без смены номера стабильной версии. Основная цель — убрать накопившиеся проблемы в боевых уведомлениях и настройках, при этом сохранить совместимость с текущей веткой `1.3.4.13`.

### 🔄 Проверка версий игроков
- Убрана причина системного сообщения `Обмениваться личными сообщениями можно только с союзниками`.
- Прямой `WHISPER`-запрос выполняется только для союзного игрока.
- Вражеский или неопределённый target больше не используется для личного запроса.
- В БГ, группе, рейде и гильдии сохранена peer-проверка через addon-сообщения.
- В открытом мире используются `target`, `mouseover`, `focus` и arena units.
- Игрок со старой версией DamageLife, в которой ещё нет peer-проверки, просто не отвечает — это ожидаемая совместимость со старой версией.
- Совпадение версий продолжает корректно отображаться в результате проверки.

### 🎯 Контроль и прерывания
- Входящий контроль: `Меня контролируют: <заклинание>!`.
- Сбитие каста: `Я сбил <заклинание> с помощью <прерывания>!`.
- Для исходящего контроля добавлены отдельные фразы по типу способности.
- Для `Запрет чар` используется DPS-формулировка: `Запрещаю <цели> использовать магию: <заклинание>!`.
- Старые шаблоны автоматически мигрируют на новые формулировки.
- Редактор теперь явно разделяет направления **«Контроль на мне»** и **«Мой контроль на врага»**.

### 🧩 Редактор выбранного контроля — Layout Fix
- Исправлен вертикальный перекос блока настроек выбранного контроля.
- `Имя файла`, поле имени, строка `Файл: ...` и заголовок редактора больше не накладываются друг на друга.
- Добавлены отдельные вертикальные интервалы между настройками звука и редактором фраз.
- Шесть строк пользовательских фраз выровнены по единой сетке.
- Кнопки `Проверить` и `Проверить звук` больше не конфликтуют с текстовыми полями.
- Исправление относится именно к отображению интерфейса и не меняет механику контроля.

### 🪟 Target Window
- Амплитуда анимации внимания при определении/обновлении специализации уменьшена.
- Пульсация и увеличение карточки стали мягче и не должны перекрывать обзор.
- Цветовая подсветка и текстовые предупреждения сохранены.

### 🎙️ Голосовые уведомления
- `CRITICAL / BURST / EXECUTE / CONTROL` больше не зависят от старых хилловских переключателей.
- Режим `VOICE/GONG` остаётся единым для боевых уведомлений.
- Сохранены резервные варианты `PlaySoundFile`.
- При невозможности воспроизведения голоса используется соответствующий гонг.
- Встроенные мужские OGG: mono 44.1 kHz Vorbis.

### ⚔️ Анонсы и эмоции
- Старые Lifesaver-фразы спасения/исцеления автоматически заменяются на DPS-фразы.
- Базовые фразы переписаны под давление, бурст, пробитие защиты, прерывание, контроль, добивание и крит.
- Исправлена вёрстка страницы `Общие → Анонсы и эмоции`.
- Описание, чекбоксы, ползунки и редактор фраз больше не должны пересекаться.
- Публичные эмоции относятся к DPS-событиям, а не к спасению союзника.
- `{target}` обозначает цель, `{spell}` — способность.

### 📦 Состав FIX 4
- Код остаётся в пределах стабильной ветки `1.3.4.13`.
- Нет BAT/EXE/PS1 и сторонних updater-программ.
- Нет автоматической замены файлов.
- Исправления рассчитаны на WoW 3.3.5a.

## v1.3.4.13 FIX 2

Исправляющая сборка стабильной ветки `1.3.4.13`.

### 🔄 Проверка версий игроков
- Ручная проверка больше не ждёт минуты и не молчит при совпадении версий.
- После запуска идёт короткое окно ожидания **2.5 секунды**, затем результат выводится в чат.
- Показывается количество ответов и версии игроков: совпадает / новее / старше.
- Более новая версия по-прежнему выводится отдельным уведомлением.
- В БГ, группе, рейде и гильдии используется общий addon-канал.
- В открытом мире используются `target`, `mouseover`, `focus` и arena units.
- WoW 3.3.5a не имеет скрытого addon-канала для всех ближайших игроков, поэтому игрок вне общего канала должен быть выбран целью или через mouseover.
- Таймер ручной проверки вынесен отдельно от стартового login timer.

### 🎯 Target Window
- Усилено именно визуальное привлечение внимания внутри самого окна.
- Важное событие вызывает крупную верхнюю плашку непосредственно на Target Window.
- Карточка временно увеличивается и пульсирует.
- Добавлена цветная вспышка по всей карточке.
- Для опасных целей появляется постоянный статус `ОПАСНАЯ ЦЕЛЬ`, `ПРИОРИТЕТ • KILL` или `EXECUTE • УБИВАТЬ`.

### ⏱️ BG Timer
- Усилено определение активного БГ через `IsInInstance()` и `GetBattlefieldStatus()`.
- Добавлено резервное определение карты через имя активного battlefield.
- Исправлена ситуация, когда таймер создавался, но его anchor оставался скрытым.
- Добавлены дополнительные локализованные названия карт.

## v1.3.4.13 FIX — стабильная сборка

### Проверка обновлений
- Добавлена peer-проверка версии DamageLife через addon-сообщения.
- Проверка не зависит от HTTP/HTTPS и не требует BAT/EXE/PS1 или внешнего запуска.
- В БГ, группе и рейде версии сравниваются через общий addon-канал.
- В открытом мире используются гильдейский канал, текущая цель и игрок под мышью.
- Добавлена ручная кнопка **«Проверить игроков»** в `/dl → О проекте`.

### Интерфейс
- Исправлено направление пользовательских полос прокрутки.
- Добавлен постоянный видимый трек прокрутки.
- Окно настроек увеличено до 880×570.
- Заголовок окна остаётся доступным при перемещении за пределы экрана.
- Выбор языка перенесён в «О проекте».
- Исправлен popup выбора шрифта.
- Тестовый `/dlswitchtest` удалён из стабильной сборки.
