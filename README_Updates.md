# DamageLife — обновления

## v1.3.4.13 — первый публичный релиз

DamageLife — боевой DPS/PvP-помощник для World of Warcraft 3.3.5a.

### Публичная версия

**Версия: 1.3.4.13**

Эта версия предназначена для установки игроками.

### Обновления через GitHub

Обновление выполняется вручную:

1. Скачать архив новой версии со страницы Releases.
2. Закрыть WoW.
3. Заменить папку `DamageLife` в `Interface/AddOns/`.
4. Запустить WoW.

Автоматической замены файлов аддона нет.

### Совместимость

- World of Warcraft 3.3.5a
- Interface 30300
- Команда настроек: `/dl`

### Правило версий

Публичные версии используют формат `vMAJOR.MINOR.PATCH`, например `v1.3.4.13` для текущей сборки проекта.

Каждый новый публичный релиз должен содержать:

- обновлённый `DamageLife.toc`;
- актуальный `VERSION`;
- описание изменений;
- готовый ZIP-архив аддона;
- отдельный GitHub Release.

### Важно

Репозиторий является основной точкой публикации проекта. Старые тестовые/автообновляющие архивы не являются публичными версиями и удаляются из основной страницы проекта.
