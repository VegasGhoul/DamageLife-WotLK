# DamageLife-WotLK

Боевой PvP/DPS-аддон для World of Warcraft 3.3.5a.

## Текущая версия

**1.3.4.13**

## Обновления

Обновления распространяются **вручную через GitHub**. Автоматической замены файлов аддона нет.

Репозиторий: `VegasGhoul/DamageLife-WotLK`

Страница релизов: https://github.com/VegasGhoul/DamageLife-WotLK/releases

## Установка

1. Скачать архив нужной версии.
2. Распаковать папку `DamageLife` в `Interface/AddOns/`.
3. Перезапустить WoW или выполнить `/reload`.

## WoW

Версия интерфейса: **3.3.5a / 30300**.

Команда открытия настроек: **/dl**.

## Примечание

GitHub используется как место публикации версий и исходных материалов проекта. Аддон не выполняет бесшумную замену своих файлов.
