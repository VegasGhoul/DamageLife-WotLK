# DamageLife — WoW 3.3.5a PvP / DPS

> Тактический PvP/DPS-аддон для World of Warcraft 3.3.5a.

**Версия:** 1.3.4.13 FIX  
**Интерфейс:** 30300  
**Команда:** `/dl`

## Что это

DamageLife — PvP/DPS-интерфейс для WoW 3.3.5a с анализом целей, burst/control/execute-событий, уведомлениями, BG Timer и инструментами для оценки боевой ситуации.

## Проверка версии

DamageLife использует peer-проверку: установленные копии аддона обмениваются версиями через `SendAddonMessage`. Это не интернет-загрузчик и не заменяет файлы автоматически.

Проверка работает в БГ, группе, рейде и гильдии. В открытом мире дополнительно используются текущая цель и игрок под мышью. Если у другого игрока обнаружена более новая версия, DamageLife сообщает об этом в чат и указывает на GitHub Releases.

В `/dl → О проекте` доступна кнопка **«Проверить игроков»**.

## Интерфейс

- исправлены вертикальные полосы прокрутки;
- добавлен видимый трек прокрутки;
- окно настроек переработано по размерам и безопасному перемещению;
- язык перенесён в «О проекте»;
- popup выбора шрифта поднят над фоном;
- сохранены уведомления SWITCH без автоматического переключения цели.

## Установка

1. Распакуйте папку `DamageLife` в `Interface/AddOns/`.
2. Перезапустите WoW или выполните `/reload`.
3. Откройте настройки командой `/dl`.

## Обновления

Публичные версии распространяются через GitHub Releases. Проверка версии только сообщает о наличии новой версии; установка выполняется вручную.
