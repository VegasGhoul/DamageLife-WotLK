# DamageLife-WotLK

Боевой PvP/DPS-аддон для World of Warcraft 3.3.5a.

## Текущая версия

**1.3.4.14**

## Обновления

В версии 1.3.4.14 добавлен высокоуровневый HTTP-слой для проверки GitHub Release, если среда предоставляет совместимый HTTP backend. Стандартный WoW 3.3.5a addon sandbox такого backend не предоставляет, поэтому DamageLife не выдаёт ложный результат и не выполняет бесшумную замену файлов.

Репозиторий: `VegasGhoul/DamageLife-WotLK`

Страница релизов: https://github.com/VegasGhoul/DamageLife-WotLK/releases

## Установка

1. Скачать архив нужной версии.
2. Распаковать папку `DamageLife` в `Interface/AddOns/`.
3. Перезапустить WoW или выполнить `/reload`.

## WoW

Версия интерфейса: **3.3.5a / 30300**.

Команда открытия настроек: **/dl**.

## Примечание

GitHub используется как место публикации версий и исходных материалов проекта. Самозамена файлов аддона не выполняется.
